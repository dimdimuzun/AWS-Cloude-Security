## Структура репозиторію

```text
.
├── README.md
├── module_01/
│   ├── presentation.en.md     # англійська (оригінал)
│   ├── presentation.uk.md     # український переклад
│   └── images/                # зображення, на які посилаються обидва файли
├── module_02/
│   └── …
└── module_07/
```

Кожен модуль — окрема папка. Англійський і український файли мають **однакову структуру**: однакова кількість слайдів, нотаток, блоків, зображень, прихованих слайдів і посилань.

## Формат файлів

Кожен слайд має вигляд:

```markdown
## Слайд 12: Назва слайда

- Вміст слайда (списки, абзаци, таблиці, зображення)

> **Нотатки:**
>
> Нотатки доповідача

---
```

- Слайди розділено рядком `---`.
- **Нотатки доповідача** йдуть після вмісту слайда, у блоці-цитаті з заголовком «Нотатки». У нотатках багатьох слайдів є блок «For accessibility: …» (опис схеми для доступності); його перекладено («Для доступності: … Кінець опису для доступності.»).
- **Приховані слайди** збережено і позначено `<!-- hidden slide -->`. У цьому курсі переважно це службові слайди «Image source files for development use only» та вихідні діаграми, з яких зроблено видимі схеми.
- **Таблиці** (правила груп безпеки, мережевих ACL, дозволи S3 тощо) перетворено на markdown-таблиці.
- **Код** (JSON політик, фрагменти журналів CloudTrail, команди) оформлено блоками ``` і **не перекладено**.
- **Посилання** збережено дослівно.

### Зображення

| Шаблон | Значення |
|---|---|
| `slideNN_imgMM.png` | MM-те зображення зі слайда NN (jpg/tiff конвертовано в PNG) |
| `slideNN_diagram.png` | **рендер усього слайда** для складних схем (насамперед приховані слайди з вихідними діаграмами та сітки з піктограмами сервісів) |

- Текст зі складних схем винесено в `<details><summary>Текст зі схеми</summary> … </details>`; основний текст слайда лишається поза блоком.
- Alt-тексти беруться **лише з презентації** (і перекладені); якщо їх немає — alt-текст порожній.
- Не включено як декоративні: значки сервісів 1,2″ без alt-тексту, індикатори прогресу, фонові фото, повторювані фото тощо.

## Принципи перекладу

- Мова перекладу — українська. Текст слайдів і нотаток **не скорочувався і не редагувався**.
- Назви сервісів AWS, абревіатури, URL, імена команд і код **залишено без змін**.
- Англійський еквівалент подано в дужках там, де в українській мові кілька варіантів: *принцип найменших привілеїв*, *поверхня атаки*, *запобіжні обмеження (guardrails)*, *політики на основі ідентичності / ресурсів*, *межа дозволів (permissions boundary)*, *керовані / вбудовані політики*, *дані в стані спокою / під час передавання (at rest / in transit)*.
- Типові відповідники для цього курсу: *шифрування на стороні клієнта (CSE) / серверне шифрування (SSE)*, *відкритий текст / шифротекст (plaintext / ciphertext)*, *ключ даних (data key)*, *конвертне шифрування (envelope encryption)*, *журналювання (logging)*, *трейл (trail)*, *сигнал (alarm)*, *усунення (remediation)*, *криміналістична ізоляція (forensic isolation)*, *реагування, кероване подіями (event-driven response)*.
- Переклад виконано вручну (не сервісом машинного перекладу), тому окремі терміни можуть відрізнятися від вашого курсового глосарія.

## Відомі особливості та обмеження

- **Одруківки оригіналу** збережено в англійському файлі й виправлено (як правило) в українському, наприклад «AMS KMS» → «AWS KMS» (модуль 5), «Date storage layer» (підпис схеми в прихованому слайді, модуль 4). Окремі випадки позначено в повідомленнях про кожен модуль.
- Надрядкові індекси в джерелі інколи втрачені («216» замість 2¹⁶); в українському тексті їх виправлено.
- Анімації (поступове розкриття відповідей на слайдах із запитаннями до іспиту) не переносяться в Markdown; відповіді присутні в тексті.
- Рендери складних схем створено за допомогою LibreOffice із резервними шрифтами, тому підписи на деяких схемах можуть злегка накладатися.
- **Модулі 1–3** збиралися раніше за решту модулів і мають дещо відмінне подання складних слайдів (текст схем частково повністю винесено в `<details>`). Вміст (текст, нотатки, зображення) повний.

## Як користуватися

- Читайте `presentation.uk.md` у будь-якому Markdown-переглядачі (GitHub, VS Code, Obsidian).
- Для порівняння мов відкрийте `presentation.en.md` поруч.
- Для автоматичної обробки: слайди розділено `---`, заголовки слайдів починаються з `## Слайд N`, нотатки — з `> **Нотатки:**`.
